# Тести

Швидко з кореня репозиторію:

- `npm test` — усі модульні перевірки (`*.test.mjs`) у Node, без браузера.
- `npm run test:e2e` — усі браузерні тести (`*-e2e.mjs`) по черзі з підсумком; `npm run test:e2e -- catalog` — лише потрібні.
- `_harness.mjs` — спільне для браузерних тестів: сервер як на GitHub Pages, запуск Chromium, кроки з підсумком.
  Той самий сервер — `npm start` (див. `scripts/serve.mjs`).

Окремі файли:

- `node --test tests/*.test.mjs` — швидкі перевірки каталогів без браузера: записи узгоджені, картки ведуть на окремі сайти.
- `node tests/catalog-e2e.mjs` — каталоги `/tools/` і `/trainers/`: картки й розділи, посилання на окремі сайти, пошук,
  вкладки, «нещодавні», перенаправлення старих адрес, сторінка 404.

Інструменти, тренажери й емулятори винесено в окремі репозиторії (`edvault-tools`, `edvault-trainers`, `edvault-emulators`) разом з їхніми тестами.

Браузерним тестам потрібен `playwright`; шляхи задаються змінними `PLAYWRIGHT_MODULE` і `CHROME`.
Спільний код (сервер, запуск браузера, кроки) — у `tests/_harness.mjs`. Сервер поводиться як GitHub Pages:
`/tools/` → `tools/index.html`, `/materials` → `materials.html`, невідома адреса → `404.html`.
