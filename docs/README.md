# Довідкові файли

- `firebase-sample-data.json` — зразок структури бази Firebase Realtime Database для порталу
  (`admin.html`, `lesson.html`, `materials.html`): адміністратори, категорії, предмети, уроки.
  Імпортуйте в Firebase Console → Realtime Database → Import JSON, щоб почати з прикладом.
  Перед імпортом приберіть ключі `_comment` і **змініть пароль адміністратора**.
